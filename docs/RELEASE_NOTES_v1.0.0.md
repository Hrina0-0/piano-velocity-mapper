把力度打不满的 MIDI 键盘的力度**实时**重映射到 1–127，经 loopMIDI 虚拟端口输出给 DAW。

## 下载

- **绿色版**：`PianoVelocityMapper.exe` —— 单个文件，双击即用，**不需要装 Python**
- **源码版**：`钢琴力度重映射-源码版.zip` —— 完整源码，自己跑 `setup.cmd`

## 用之前必须做一件事

这个工具要把重映射后的力度送进 DAW，中间需要一个**虚拟 MIDI 端口**（硬件 MIDI 口
是独占的，工具占着键盘之后 DAW 就只能听虚拟口）。

1. 装 [loopMIDI](https://www.tobias-erichsen.de/software/loopmidi.html)（个人使用免费）
2. 打开 loopMIDI，右键托盘图标 →「添加端口」，名字随意（比如 `Piano`）
3. 启动本工具，它会**自动帮你把 loopMIDI 启动起来**并自动选好端口

没装 loopMIDI 也没关系：工具启动时会弹引导窗，里面有官网直达链接。

## 接线

把工具的「输出（虚拟端口）」和 DAW 的 MIDI 输入**选成同一个端口**。

以 Cubase 为例：`设备 > MIDI 端口` 勾上那个虚拟端口，工具的输出也选它。

## 说明

- 首次启动会解压内置依赖，慢一两秒属正常
- 端口卡片下面有一行提示，绿色表示当前用的是虚拟端口（对了），橙色表示选成硬件口了（DAW 收不到）
- 点右上角 ✕ 会问「要完全退出这个工具吗？」：留在后台运行就缩到托盘继续转发
- 设置存在 exe 旁边的 `config.json`，换电脑复制过去即可
- 程序本身**不含**任何第三方软件；pygame (LGL) / mido (MIT) 的许可说明见源码包
