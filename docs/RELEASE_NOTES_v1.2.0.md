# v1.2.0 发布说明

## 下载

**`PianoVelocityMapper-v1.2.0.zip`**（≈18 MB）——解压双击 `PianoVelocityMapper.exe` 就能用，
**不需要装 Python**。

只有这一个包。源码就在这个仓库里（MIT 许可，右上角 **Code → Download ZIP**）。

## 用之前必须做一件事

装一个**虚拟 MIDI 端口**（loopMIDI 等），否则 DAW 收不到重映射后的力度：

<https://www.tobias-erichsen.de/software/loopmidi.html>

装好之后本工具会**自动帮你启动它**，平时只需要开这一个软件。

## v1.2.0 更新了什么

- **端口下拉列表可以滚动了**：端口多的时候，弹出的浮层会自动收进屏幕内；
  滚轮、方向键、右侧滚动条都能翻到最后一项，不会再出现「靠后的端口跑到屏幕外点不着」。
- **输出端口不会再被自动改成会发声的设备**：配置里的输出端口一时找不到时，程序只回退到
  **虚拟端口**（静音），绝不退到 `Microsoft MIDI Mapper` 或系统音源——以前那样会让
  你弹的音符真的从钢琴发出来。
- **分发改成只发一个包**：原来有「绿色版 + 源码版」两个包，现在统一成
  `PianoVelocityMapper-v<版本>.zip`，本地和 GitHub 上是同一个文件、同一个名字。
- 其它功能见 [README](../README.md)：界面中英双语切换（默认中文）、托盘常驻、
  虚拟端口自动接管、智能标定、力度曲线。

## 已知事项

- 第一次启动会解压内置依赖，慢一两秒属正常。
- loopMIDI 由使用者自行安装，本项目**不附带**（作者许可不允许再分发）。
- 压缩包里不含任何第三方软件。
