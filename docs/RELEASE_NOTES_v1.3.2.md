# v1.3.2 发布说明

## 下载

**`PianoVelocityMapper-v1.3.2.zip`**（≈18 MB）——解压双击 `PianoVelocityMapper.exe` 就能用，
**不需要装 Python**。

只有这一个包。源码就在这个仓库里（MIT 许可，右上角 **Code → Download ZIP**）。

## 用之前必须做一件事

装一个**虚拟 MIDI 端口**（loopMIDI 等），否则 DAW 收不到重映射后的力度：

<https://www.tobias-erichsen.de/software/loopmidi.html>

装好之后本工具会**自动帮你启动它**，平时只需要开这一个软件。

## v1.3.2 更新了什么

**修复：换到别的电脑上，输入端口那一栏显示的是别人机器上的设备名。**

老版本把默认输入端口写死成了 `Digital Piano`（作者自己那台琴的名字）。
发给别人之后，对方机器上根本没有这个设备，界面上却一直显示着它：

```
输入（键盘）  Digital Piano      ← 这台机器上根本没有这个口
运行日志       [等待] 未找到输入端口 'Digital Piano'...
```

看起来就像"这软件坏了"。

现在改成：

- **默认输入端口改为自动匹配**：启动时自己挑一个，优先挑名字里带
  `piano` / `keys` / `keyboard` 的那种真键盘；挑不出来就不乱连，
  显示「（无可用端口）」，等你插上键盘再点「刷新端口」。
- **端口确实不存在时，界面会明说**：显示 `⚠ 某某 · 未找到`（橙色），
  而不是把一个不存在的设备名当成正常选项显示。端口卡片下面也会提示
  「没找到输入端口，请重新选择」。
- **运行日志里列出当前实际可用的输入端口**，照着选最快。
- **旧版本留下的脏配置会自动清理**：如果你之前已经用过带这个毛病的版本，
  升级后它会自动改回自动匹配，不用手动改配置文件。
  （你自己手动选过的端口名不会被动。）

顺带：`config.json` 里存的是本机端口名，每台机器都不一样，
所以它不再跟着源码仓库发布，仓库里改放一份 `config.example.json` 供参考。

## v1.3.1 带来的（还没用上的记得升）

**修复：端口下拉列表滚不动、最后一行被削掉半截。**

- **列表比屏幕放得下的高度还长时，滚轮基本滚不动。**
  原因是每次滚动都会把列表行销毁重建，而正在接收滚轮事件的那一行
  被销毁掉了，同一次滚动的后续事件就全丢了 —— 表现成「滚一下只动一行」，
  排在后面的端口根本选不到。
  现在改成**行控件复用**（滚动时只换文字和颜色），滚轮跟手、不闪、不丢事件。
- **列表最后一行被削掉半截。**
  原因是行高写死成 30px，而 9 号字体的行加上下内边距实际是 33px，
  浮层比内容矮 3px/行，9 行下来最后一行就露不全。
  现在行高**按字体实测**，一行不多一行不少。
- **一次能显示更多端口**：以前最多 9 行，现在最多 14 行，并按屏幕剩余空间自动收缩。
- **浮层宽度自适应**：端口名太长时会自动加宽，不会被截断。
- **新增键盘操作**：`↑` `↓` 移动，`PgUp` `PgDn` 整屏翻，`Home` `End` 跳到首尾，`Esc` 关闭。

## v1.3.0 带来的（还没用上的记得升）

- **运行日志不再刷屏**：
  - 连续出现的**同一句话**会合并成一行，后面标「×N」（例如 `已最小化到后台…（×6）`），
    不会再把其它日志全淹掉；
  - 「已最小化到后台」这类提示只在**真正收起窗口时**记一次——以前窗口最小化时
    系统会连发好几个最小化事件，同一句话能刷出几十行。
- **修复：改端口时日志面板会报错**。带 `[配置]` 前缀的日志行在着色判断上写错了
  `startswith` 的用法，一改端口就会抛异常、界面日志刷新不出来。

## v1.2.0 带来的（还没用上的记得升）

- **端口下拉列表可以滚动了**：端口多的时候弹出的浮层会自动收进屏幕内；
  滚轮、方向键、右侧滚动条都能翻到最后一项。
- **输出端口不会再被自动改成会发声的设备**：配置里的输出端口一时找不到时，
  程序只回退到**虚拟端口**（静音），绝不退到 `Microsoft MIDI Mapper` 或系统音源。
- **只发一个包**：`PianoVelocityMapper-v<版本>.zip`，线上与本地同名。
  （线上包由 GitHub Actions 构建，与本地手工打包的环境不同，字节可能有细微差异，功能一致。）

## 已知事项

- 第一次启动会解压内置依赖，慢一两秒属正常。
- loopMIDI 由使用者自行安装，本项目**不附带**（作者许可不允许再分发）。
- 压缩包里不含任何第三方软件。
