# 钢琴力度重映射 · 源码版

这是完整源码包。给想改点东西、或者想在别人机器上自己装环境的人。

## 快速开始

1. 装 Python **3.10 ~ 3.13**（<https://www.python.org/downloads/>，安装时勾上
   *Add Python to PATH*）
2. 双击 **`setup.cmd`**
   - 自动建虚拟环境、装依赖（mido / pygame）、在桌面创建快捷方式
   - 最后会打印一次 MIDI 端口体检：告诉你系统里有哪些端口、有没有虚拟端口
3. 桌面上的 `钢琴力度重映射` 快捷方式就是启动入口（不弹黑窗口）

## 跑起来之后

和绿色版一样，需要一个**虚拟 MIDI 端口**（loopMIDI 之类）：
工具会自动找到你机器上已安装的 loopMIDI 并自动启动它；没装的话会弹引导窗。

细节看同目录下的 `README.md`。

## 目录里都是什么

| 文件 | 作用 |
| --- | --- |
| `app.py` | 入口：双击运行的本体 |
| `gui.py` | 图形界面（tkinter 自绘） |
| `tray.py` | Windows 托盘图标（纯 ctypes，不依赖第三方库） |
| `engine.py` | MIDI 后台线程：收音符 → 映射力度 → 发出去 |
| `velocity_mapper.py` | 核心映射逻辑 + 端口查找 |
| `midi_ports.py` | 虚拟端口检测 / 找 loopMIDI / 自动拉起它 |
| `aa.py` | 抗锯齿绘图（借 pygame 在高分辨率画好再缩小） |
| `webui.py` / `webui.html` | 可选的网页控制台 |
| `paths.py` | 区分「只读资源目录」和「可写数据目录」（打包 exe 时要用） |
| `check_ports.py` | 环境体检脚本，setup.cmd 末尾会调用 |
| `build_exe.py` | 想打成绿色版 exe 时用这个 |
| `config.json` | 你的设置（最大力度、曲线、端口） |
| `ui_prefs.json` | 界面偏好（比如关闭时要不要询问） |

## 打成绿色版 exe

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt pyinstaller
.venv\Scripts\python build_exe.py
```

产物在 `dist/PianoVelocityMapper.exe`（≈18 MB，单文件、免安装）。
