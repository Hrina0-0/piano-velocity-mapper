# 钢琴力度重映射

下载解压后，**双击 `PianoVelocityMapper.exe` 就能用**，不需要装 Python。

---

## 一、先做一件事：准备一个虚拟 MIDI 端口

这个工具的工作方式是：

```
键盘  ──►  钢琴力度重映射  ──►  你的 DAW
            （把力度 1~87 映射成 1~127）
```

中间这一段需要一个**虚拟 MIDI 端口**：因为 MIDI 硬件端口是独占的，工具占着键盘的
输入口之后，DAW 就只能去听一个「虚拟端口」。

**如果你电脑上已经装了 loopMIDI**：什么都不用做，直接双击 exe 即可——
工具会自动找到 loopMIDI、**自动帮你把它启动起来**、并自动选好端口。

**如果还没有**：装一个 loopMIDI（个人使用免费）

1. 打开 <https://www.tobias-erichsen.de/software/loopmidi.html> 下载安装
2. 打开 loopMIDI，右键点击它托盘里的图标 →「添加端口」，名字随意（比如 `Piano`）
3. 回到本工具，双击 exe。启动后界面右下角会有一行绿色提示告诉你选哪个端口

> 工具界面上的「端口」卡片会直接告诉你当前用的是不是虚拟端口。
> 如果显示橙色的「是硬件端口，DAW 收不到重映射后的力度」，说明选错了。

## 二、接进 DAW

把工具的「输出（虚拟端口）」和 DAW 的 MIDI 输入**选成同一个端口**。

以 Cubase 为例：`设备 > MIDI 端口` → 勾上那个虚拟端口 → 工具的输出也选它。

## 三、几个说明

- **点右上角 ✕ 会问你要不要完全退出**：选「留在后台运行」就缩到托盘继续转发
  （托盘图标在任务栏右下角，可能藏在 `^` 展开的折叠区里），选「完全退出」才结束。
- 工具的设置（最大力度、曲线）存在 **exe 旁边的 `config.json`** 里，换电脑就复制过去。
- 端口列表项很多时，弹出的浮层会自动收进屏幕里；滚轮、方向键、右侧滚动条都能翻到
  最后一项，不会出现「靠后的端口点不着」。
- 第一次启动如果没装 loopMIDI，工具会弹一个引导窗，点「打开 loopMIDI 官网」即可。
- 程序文件本身是干净的单一 exe（≈18 MB），**不含**任何第三方软件；
  loopMIDI 是你们自己从官网装的。
