# GitHub 用户名改名 · 操作手册

> 目标：把账号用户名 `lanminhua666-dotcom` 改成 `Hrina0-0`。
> 仓库名 `piano-velocity-mapper` **不用改**，改的只是 URL 里 `owner` 那一段。

---

## 一、你为什么想改它（背景）

`lanminhua666-dotcom` 是 **GitHub 注册时按你的邮箱自动生成的掩码占位名**，
不是你手动起的。仓库地址因此长这样：

```
https://github.com/lanminhua666-dotcom/piano-velocity-mapper
                  ^^^^^^^^^^^^^^^^^^^^ 这一段是邮箱映射
```

改成 `Hrina0-0` 后：

```
https://github.com/Hrina0-0/piano-velocity-mapper
```

附带好处：URL 不再暴露邮箱特征，隐私上更干净。

---

## 二、改名前已经做完的准备工作

| 项目 | 状态 | 说明 |
|---|---|---|
| 提交邮箱换成带数字 ID 格式 | ✅ 已完成 | `275496685+lanminhua666-dotcom@users.noreply.github.com` |
| 候选名可用性实测 | ✅ 已完成 | `Hrina0-0` 返回 404 = 未被占用 |
| 候选名格式合法性 | ✅ 已完成 | 只含字母数字与单个连字符，长度 8 ≤ 39 |
| 改名后收尾脚本 | ✅ 已就绪 | `dev/after_rename.ps1` |

**为什么提交邮箱要换成带 ID 的格式？**

GitHub 有两代 noreply 邮箱格式：

- 旧格式 `用户名@users.noreply.github.com` —— 改名后**会失去归属**，提交不再计入贡献图
- 新格式 `数字ID+用户名@users.noreply.github.com` —— 数字 ID 是账号的稳定标识，**改名后依然关联**

你仓库原有 14 个提交用的正是旧格式。已经改成新格式后，
今后新提交在再次改名也不会掉署名。

## 三、你需要手动做的（浏览器操作，约 1 分钟）

1. 打开 <https://github.com/settings/account> 并登录
2. 页面往下滚到 **Change username** 区块，点 **Change username**
3. 读一遍警告，点 **I understand, let's change my username**
4. 输入新用户名：

   ```
   Hrina0-0
   ```

5. 点 **Change my username**
6. GitHub 会要求你**重新输入密码**（有 2FA 还会要验证码）→ 这一步由你本人输入
7. 完成后页面会显示新用户名

> 改名**立即生效**。旧用户名 `lanminhua666-dotcom` 会被释放给其他人认领，
> 所以改名后请尽快跑收尾脚本（第 4 步）。

## 四、改名后跑收尾脚本（我来做）

改完名后，在 PowerShell 里执行：

```powershell
cd D:\Codex-work\repiano_pkg
powershell -ExecutionPolicy Bypass -File dev\after_rename.ps1 -NewName Hrina0-0
```

脚本会依次：

1. 确认账号已改名为 `Hrina0-0`（没改成功就跳过，不动本地仓库）
2. 更新 `git remote origin` → `https://github.com/Hrina0-0/piano-velocity-mapper.git`
3. 把提交邮箱更新为 `275496685+Hrina0-0@users.noreply.github.com`
4. 校验 Release 附件在新用户名下仍能下载 + 提交署名归属

## 五、改名后各处的变化

| 位置 | 改名后 |
|---|---|
| 仓库网页 | 旧链接自动跳转，新地址 `github.com/Hrina0-0/...` |
| `git push` / `git pull` | 旧 remote 仍可用，脚本会改成新地址 |
| Release 下载 | 附件随仓库迁移，新地址 `github.com/Hrina0-0/piano-velocity-mapper/releases` |
| 个人主页 `github.com/lanminhua666-dotcom` | **404**，无跳转（官方不支持主页重定向） |
| @提及旧用户名 | 不跳转 |
| 已有 14 个提交的署名 | 靠第二节的带 ID 邮箱保住归属 |
| CI 工作流 | 不用改（用的是 `${{ github.ref_name }}`，不写死用户名） |
| README 里的下载链接 | 不用改（用的是相对路径 `../../releases`） |

## 六、注意事项

- 官方文档目前**没有**为 github.com 个人账号列出改名冷却期，
  但旧用户名会**立即**被释放，可能被他人抢注。建议改名当天就跑收尾脚本。
- 你的账号只有 1 个公开仓库、0 star / 0 fork / 0 clone，
  不满足「仓库名被永久停用」的触发条件（Marketplace Action 或周 clone/Action 使用超 100 次），
  所以改名不会造成任何不可逆损失。
- 自用版 `D:\Codex-work\repiano` 没有 `.git`，与改名无关，完全不受影响。
